# Minecraft Liminal Industries Mapper App

WIP

Serves as hand-drawn map notebook. Implemented as a single self-contained webpage.
Stores data in browser's local storage, with import/export.

* Room templates
* Map which consists of rooms placed from template palette
* Build route between two rooms
* Specify door/exit pattern for each room side
* Manually open/close door between any two rooms on the map
* Room names and bookmarks
